What does an Availability Zone give? | Isolated data centres | A billing group | A user role | Servers close to each user | Using several protects against a site failure.
Who secures the operating system on an EC2 instance? | The customer | AWS | The browser | The region | This is the shared responsibility model.

## Serverless Computing

## Ansible

## Jenkins

## GitHub Actions

## GitLab CI

## Argo CD

## Prometheus & Grafana

## Site Reliability Engineering

## Linux Administration

## OpenShift
